RQ1 PoC: three APIs, one message (paper Figure 1)

FProot's slices of Screen.width, Window.devicePixelRatio and VisualViewport.width all end in one Mojo message, VisualProperties. The browser sends it whenever the page's widget changes, and it carries the screen, the zoom and the visible size. Change any of these and watch the three APIs move together. A defense that rewrites only one of them leaves the message readable through the others.
