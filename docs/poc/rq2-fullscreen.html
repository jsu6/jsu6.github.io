RQ2 PoC: Brave protects screen.width, not the screen

Brave rewrites screen.width in its default (Standard) profile. In fullscreen, the page's visual viewport covers the whole screen, and Brave does not rewrite visualViewport.width. So one click returns the true screen width. Nothing leaves this page: values are only shown, and copied when you ask.
