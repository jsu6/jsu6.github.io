RQ2 PoC: readers Brave leaves unprotected (no click needed)

Brave's audio, screen and WebGL defenses hook some readers of the audio device, the display and the GPU. Other readers of the same information pass no hook, or pass a hook that leaves their value as it is. The page compares them with protected siblings: navigator.hardwareConcurrency, which Brave farbles per site, and a WebGL limit that the same getParameter hook lowers.

WebGL limits differ (farbled, and a few limits lowered by one on each site).
