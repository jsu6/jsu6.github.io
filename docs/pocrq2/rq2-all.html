RQ2 PoC: every reader our run found circumventing a Brave defense

The 305-API run graded 226 APIs as reaching information a Brave defense protects without a hook that acts at Brave's default level. This page runs the exact probe our lab ran for the 189 a page can read (the other 37 need a paint worklet, hardware or a permission prompt) and lists each one's value. Nothing leaves this page.

How to verify

  1. In Chromium or Chrome, click Run the probe (about 30 s; scroll the mouse wheel over the page when asked, for the wheel readers), then Copy readings.
  2. In Brave on the same machine, Shields at their default, run it again and paste the Chromium readings.
  3. Each row then shows Chromium's value (the ground truth), Brave's value, and our lab's outcome. A leaked row should read the same in both browsers; a rewritten one should differ. Partly: the second value (WebGL) leaks while the first (getImageData) is farbled.

The probe also asks for the Screen details permission (window management); allowing it lets the ScreenDetailed readers run.
