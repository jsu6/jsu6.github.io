RQ2 proofs of concept: defenses that protect APIs, not information

Minimal pages behind RQ2 of the paper Slicing to the Roots. Each page prints the exact code it runs and only shows values on the page; nothing is sent anywhere. Open a page in Chromium or Chrome first, copy the readings, then open it in Brave (Shields at their default) on the same machine and paste them to compare.

  • Fullscreen screen bypass: Brave rewrites screen.width, but in fullscreen visualViewport.width is the true screen width. Needs one click.
  • Unprotected readers: devicePixelRatio, the audio sample rate and base latency and the WebGL renderer string are the same as in Chromium, while hardwareConcurrency and the WebGL limits read through the same getParameter call are farbled.
  • Canvas pixels through WebGL: getImageData is farbled, but the same canvas read through WebGL readPixels is not.
