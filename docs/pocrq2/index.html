RQ2 proofs of concept: defenses that protect APIs, not information

Minimal pages behind RQ2 of the paper Slicing to the Roots. Each page prints the exact code it runs and only shows values on the page; nothing is sent anywhere, and no page asks for a permission.

What we found

Seeded with the 305 APIs Chromium marks [HighEntropy], our analysis finds 233 APIs that read information a Brave defense protects. At Brave's default level (Standard), a hook sits on the path of 7. The other 226 reach the same information without passing a hook that acts at Standard, so they circumvent the defense. In Brave 1.92.144 (two sites, two sessions each), of the 226:

  • 92 returned exactly the value Brave returns with fingerprinting protection off;
  • 49 leaked through one read-back route: canvas drawing calls, farbled through getImageData but not through WebGL;
  • 36 were rewritten after all, 46 could not be checked by a page, and 3 are indistinguishable on our machine (the protected value equals the true one).
