Canvas: Brave protects getImageData, not the canvas pixels

Brave adds per-site noise to the canvas pixels returned by getImageData and toDataURL. Our analysis shows that OffscreenCanvas.transferToImageBitmap reaches the same source (the canvas pixels mapped back from GPU memory) without passing those hooks (the paper's motivating example). A page that turns the canvas into a bitmap and reads it back through WebGL gets the true pixels.
