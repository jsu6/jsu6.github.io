WebGL: Brave changes the limits, not the GPU name, in the same call

WebGL fingerprinting reads the graphics card's name and limits through getParameter. Brave hooks getParameter and, at its default level, lowers a few of the MAX_* limits per site. Our analysis shows that the hook leaves the renderer string it reads unchanged: the field it protects is not the field a page reads. The same call returns the true GPU and driver name.
