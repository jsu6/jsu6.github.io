RQ2 PoC: 2D canvas pixels read back through WebGL

Brave farbles getImageData in its default profile, but its WebGL read-back hooks act only at the Strict level. A page can copy a 2D canvas into a WebGL texture and read it with readPixels. The page draws one opaque scene, then reads its pixels both ways.
