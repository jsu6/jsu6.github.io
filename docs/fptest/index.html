FPtest: web API readings

A research page (NC State). It reads the values 100 web APIs found by tracing Chromium's source, and 25 randomly chosen control APIs, return in your browser.

Nothing leaves this page by itself: there is no server, no cookie, no third-party script. The readings stay in this tab until you press Download JSON, which saves them as a file on your device. Close the tab to discard them.

1. Read the APIs

Takes about a minute. Some APIs return nothing on some browsers; that is recorded too.

2. Optional: readings that need your permission or action

Each button asks the browser for one permission or chooser; you can decline.
