RQ2: the confirmed bypasses, API by API

Our slices predict 33 APIs that read information a Brave defense protects but escape its default hooks. In Brave 1.92.144, 29 of them returned the same value as with protection off. This page reads 24 of the 29 in Brave and in Chromium; the other five need a user event or a permission (two WheelEvent and three ScreenDetailed attributes).

Nothing leaves this page, and it asks for no permission. Results move between the two windows only when you copy and paste them. Hooks as in Brave 1.92.144 (brave-core aeb45b6b); Chromium source 150.0.7871.186.

How to check

  1. In both browsers (Brave with Shields at their default, and Chromium or Chrome, on the same machine and display, with windows the same size and smaller than the screen, and page zoom at 100%), press Run.
  2. In Chromium, press Copy results.
  3. In Brave, paste them and press Compare.
A bypass works when both hold in Brave: a hooked sibling, an API the same defense changes at the default level, returns a different value from Chromium's (the defense is active), and the API returns Chromium's value (the hook missed it). For the Strict-only rows, and for the two canvas rows whose hook acts only at Strict, nothing is hooked in a default profile, so only the second part applies. The user-agent rows also differ when the two browsers' versions differ.
