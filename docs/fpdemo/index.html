FPdemo: reading what Brave's fingerprinting hooks hide

Brave hides fingerprinting information by changing the value of the specific web APIs it hooks. The same information often reaches the page through other APIs that it does not hook. This page reads each piece of information both ways and compares the results between Brave and Chromium.

Nothing leaves this page: no server, no cookie, no storage, no third-party script. Results move between the two windows only when you copy and paste them yourself. Hooks are as in brave-core v1.92.144.

How to check

  1. In both windows (Brave with Shields at their default, and Chromium of the same version, both at 100% page zoom), press Run. It enters fullscreen for a moment to measure the screen, then reads the rest.
  2. In Chromium, press Copy results.
  3. In Brave, paste them below and press Compare.
A bypass works when all three hold:
  1. In Chromium, the route returns the same value as the hooked API. So the route reads the real information.
  2. In Brave, the hooked API returns a different value from Chromium's. So Brave's hook is active and changes it.
  3. In Brave, the route still returns Chromium's value. So Brave's hook missed it.

How each route works

Screen size

Hooked: screen.width × screen.height. Brave hands Screen a copy of the screen information with the size replaced by a common desktop size.
Route: in fullscreen the viewport is the screen, and visualViewport is not hooked. This needs one click, which the Run button provides, and page zoom at 100%.
Optional route: getScreenDetails() (the Window Management API) returns the real size of every screen after a permission prompt. Brave has no override for it.

await document.documentElement.requestFullscreen();
const route = [visualViewport.width, visualViewport.height];   // = screen.width/height when unhooked
const details = await getScreenDetails();                      // after the permission prompt
const route2 = [details.currentScreen.width, details.currentScreen.height];

double DOMVisualViewport::width() const {
  LocalFrame* frame = window_->GetFrame();
  if (!frame)
    return 0;

  if (!frame->IsOutermostMainFrame()) {
    // Update layout to ensure scrollbars are up-to-date.
    frame->GetDocument()->UpdateStyleAndLayout(
        DocumentUpdateReason::kJavaScript);
    auto* scrollable_area = frame->View()->LayoutViewport();
    float width =
        scrollable_area->VisibleContentRect(kExcludeScrollbars).width();
    return AdjustForAbsoluteZoom::AdjustInt(ClampTo<int>(ceilf(width)),
                                            frame->LayoutZoomFactor());
  }

  if (Page* page = frame->GetPage())
    return page->GetVisualViewport().Width();

  return 0;
}

At the default level, Brave lowers a limit by 1 or leaves it, by a pseudo-random draw per site and session.

ScriptValue FarbleGLIntParameter(WebGL2RenderingContextBase* owner,
                                 ScriptState* script_state,
                                 GLenum pname,
                                 int discard) {
  GLint value = 0;
  if (!owner->isContextLost())
    owner->ContextGL()->GetIntegerv(pname, &value);
  if (value > 0) {
    brave::FarblingPRNG prng =
        brave::BraveSessionCache::From(*ExecutionContext::From(script_state))
            .MakePseudoRandomGenerator();
    prng.discard(discard);
    if (prng() % 2 != 0) {
      value = value - 1;
    }
  }
  return WebGLAny(script_state, value);
}
