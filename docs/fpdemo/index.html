FPdemo: reading what Brave's fingerprinting hooks hide

Open this page in Brave and in Chromium of the same version, side by side. Brave changes the value of an API it hooks. For each piece of information, this page reads it twice: once through the API Brave hooks, and once through a route that avoids the hook.

■ Hooked API: Brave changes this value. ■ Route around the hook: reads the same information another way.

How to read it. In Chromium the two sides agree (green). In Brave they disagree (red): the hook changed one side and missed the other. The route's value is the same in both windows, so it is the real one. Colour swatches make long values easy to compare between the windows.

Nothing leaves this page: no server, no cookie, no storage, no third-party script. Hooks are as in brave-core v1.92.144; file names refer to Brave's chromium_src/third_party/blink/renderer/.

const display::ScreenInfos& ChromeClientImpl::BraveGetScreenInfos(
    LocalFrame& frame) const {
  LocalDOMWindow* dom_window = frame.DomWindow();
  if (!dom_window) {
    return GetScreenInfos(frame);
  }
  ExecutionContext* context = dom_window->GetExecutionContext();
  if (!brave::BlockScreenFingerprinting(context)) {
    return GetScreenInfos(frame);
  }
  display::ScreenInfo screen_info = GetScreenInfo(frame);
  screen_info.rect = gfx::Rect(allowed_desktop_screen_sizes.back().width(),
                               allowed_desktop_screen_sizes.back().height());
  const int outerWidth = dom_window->outerWidth();
  const int outerHeight = dom_window->outerHeight();
  for (const auto& size : allowed_desktop_screen_sizes) {
    if (size.width() >= outerWidth && size.height() >= outerHeight) {
      screen_info.rect = gfx::Rect(size.width(), size.height());
      break;
    }
  }
  screen_info.available_rect = screen_info.rect;
  screen_info.is_extended = false;
  screen_info.is_primary = false;
  screen_infos_ = display::ScreenInfos(screen_info);
  return screen_infos_;
}

visualViewport.width reads the page's visual viewport, not the screen information. Brave has no override of this file (its chromium_src/…/core/frame/ has no dom_visual_viewport.cc), so in fullscreen it returns the real screen width.

double DOMVisualViewport::width() const {
  LocalFrame* frame = window_->GetFrame();
  if (!frame)
    return 0;

  if (!frame->IsOutermostMainFrame()) {
    // Update layout to ensure scrollbars are up-to-date.
    frame->GetDocument()->UpdateStyleAndLayout(
        DocumentUpdateReason::kJavaScript);
    auto* scrollable_area = frame->View()->LayoutViewport();
    float width =
        scrollable_area->VisibleContentRect(kExcludeScrollbars).width();
    return AdjustForAbsoluteZoom::AdjustInt(ClampTo<int>(ceilf(width)),
                                            frame->LayoutZoomFactor());
  }

  if (Page* page = frame->GetPage())
    return page->GetVisualViewport().Width();

  return 0;
}
