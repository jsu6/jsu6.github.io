RQ3 PoC: the APIs the slice ranking found that change with the device

Of the slice model's top 100 APIs, 84 are used by no prior work. Five of them changed with one configuration setting on our test machine and were stable on reload; seven more did once the Screen details (window-management) permission was granted. One of 100 random controls changed. This page reads the twelve the way a page would. Nothing leaves this page.

How to test

  1. Click Read (and, in Chrome or Edge on a desktop, Read with permission, then allow Screen details). Click Copy readings and keep the text.
  2. Reload, read again, paste the first readings and click Compare: on the same device and browser every value should be the same (stable).
  3. Read on another device or browser, paste and compare: a value that differs separates the two.
