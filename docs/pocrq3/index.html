RQ3 PoC: read the newly found APIs on your device

The slice model's top 100 APIs include that no prior fingerprinting work uses; of them a page reads without asking for a permission. This page runs, for each of those, the same probe our lab ran (item 3.4) and lists the raw value. It asks for no permission. It does not judge or compare. Copy the results and send them to us; readings from many devices, browsers and settings are aggregated later to see which values differ between devices. Nothing is sent by the page itself.

How to take part

  1. Optional, before running: if you have a gamepad, press one of its buttons.
  2. Click Run all. It takes up to a few minutes; keep this tab in front, and allow the test window to open.
  3. Type the test machine, browser and visit number in Test label, e.g. mac chrome 1.
  4. Click Copy results and paste the text into a message to us. The label is saved with the results. Running again later (the next visit number), or in another browser, helps too.

The code

probes.js holds the probes, copied unchanged from the lab page with the helpers they call. The script at the bottom of this page runs them. Four probes the lab could not run, because they need a popup opened by a click, are replaced there by versions that use your click. The lab column is the verdict from out/experiments/3.4/verdicts.csv (TP: changed with one setting and stable on reload).
